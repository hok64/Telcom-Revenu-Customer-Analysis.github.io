# # 📊 Telecom Revenue & Customer Analytics Dashboard

## 📌 Project Overview

This project simulates a real-world telecommunications analytics environment using Python and Power BI.

The objective was to analyze customer behavior, revenue performance, service usage, and business KPIs for a fictional telecom company operating in the Democratic Republic of Congo (DRC).

The project focuses on transforming raw telecom data into actionable business insights through data analysis, data modeling, and interactive dashboards.

---

# 🎯 Business Objectives

* Analyze telecom revenue performance
* Monitor customer growth and segmentation
* Track data consumption and call usage
* Identify top-performing cities and service plans
* Calculate key telecom KPIs such as ARPU
* Build executive-level dashboards for decision-making

---

# 📂 Dataset Description

The dataset was fully generated and simulated using Python.

### Tables Created

| Table     | Description                      |
| --------- | -------------------------------- |
| customers | Customer demographic information |
| plans     | Telecom subscription plans       |
| usage     | Monthly telecom usage history    |
| revenue   | Monthly customer revenue         |

---

# 📈 Key KPIs

* Total Revenue
* Monthly Revenue
* ARPU (Average Revenue Per User)
* Number of Customers
* Average Data Usage
* Revenue by City
* Revenue by Plan
* Top Data Consumers

* Average call minutes

---

# 📌 Key Insights

* Gold and Unlimited plans generated the highest revenue.
* Kinshasa and Lubumbashi were among the top-performing cities.
* Unlimited subscribers showed significantly higher data consumption.
* Revenue trends remained stable across the 2-year period.
